# GM-Scriptorium

A compiled command-line tool that turns your Obsidian-style tabletop campaign vault into a
player-safe website, built on top of the [gm-apprentice](https://github.com/AntTheLimey/gm-apprentice)
generator.

Everything a GM writes in a campaign vault (what's really behind a mystery, secret NPC motives, stat
blocks that would spoil a fight) is not meant for players. GM-Scriptorium's whole job is turning
that vault into a site your players *can* see, with read-only leak checks that refuse to publish if
GM-only content would end up on it. It also adds themes, a per-campaign vocabulary pack and a local
GM admin panel.
