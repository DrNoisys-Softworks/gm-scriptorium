# Publish manifest

This is the player site's allowlist. With `publish.mode: player`, a page publishes only if its vault path is ticked under Publishing. Anything unlisted stays off the site.

To publish a page, add one bare line under Publishing: a dash, a ticked box, a space, and the vault-relative path exactly as it is on disk. Put notes in this paragraph, never on an entry line.
