# Relationship types

The relationship words this sample vault actually uses. Pick the most specific type. Store one direction only; the inverse is implied. Symmetric types are stored once.

| Category | Types |
|---|---|
| Kinship | ancestor_of |
| Social | knows, mentors, trusts, rival_of, betrayed |
| Power | leads, serves, employs |
| Affiliation | member_of |
| Spatial | located_at, headquartered_at, part_of, borders |
| Possession | owns, created, wields, seeks, founded |
| Knowledge | discovered, recorded_in, studies |
| Conflict | enemy_of, exiled_from |
| Economic | trades_with, finances, indebted_to |
| Historical | negotiated_with, caused |
| Supernatural | bound_to |

**Symmetric (stored once):** knows, rival_of, trades_with, borders.

## House notes for The Long Lease

- `negotiated_with` is the verb for anyone who has bargained with the dragon, in either century.
- `indebted_to` covers money owed to the Marrable house. Use `serves` only where someone takes orders.
- An edge whose existence is itself a secret carries `gm_only: true`, so the published site never draws it.

**Tone values:** friendly, respectful, professional, hostile, fearful, distrustful, contemptuous, neutral, complicated. **Strength:** 1 to 10.
